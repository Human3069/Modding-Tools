# StarCraft 1.16.1 TBL Compiler

TblCompiler.exe를 더블 클릭하여 실행합니다. WinForms / .NET Framework 4.x 프로그램입니다.
TXT 선택 → 출력 위치 선택 → 인코딩 선택 → TBL 컴파일 + 검증 순서로 사용합니다.
기본 출력은 도구의 output/stat_txt.tbl입니다. 원본 origins/rez/stat_txt.tbl은 자동으로 덮어쓰지 않습니다.
이미 있는 출력에 저장하면 직전 버전을 같은 경로의 .bak에 보관합니다.

입력 TXT는 UTF-8(BOM 유무 모두 지원)로 저장하세요. 입력 TXT의 저장 인코딩과 출력 TBL의 문자 인코딩은 별개입니다.
기본 출력은 Windows-1252로 기존 영어 TBL에 맞습니다. 한글은 CP949 선택이 가능하지만 실제 게임의 한글 글꼴/표시 환경이 별도로 필요합니다.
표현할 수 없는 문자는 ?로 바꾸지 않고 오류로 중단합니다. UTF-16/CP949 TXT는 먼저 UTF-8로 저장하세요.

한 줄은 한 문자열 항목입니다. 줄 순서, 빈 줄, 앞뒤 공백을 모두 보존합니다.
#으로 시작하는 줄도 주석으로 취급하지 않으며 문자열 항목이 됩니다. 별도 번호나 설명 줄을 삽입하지 마세요.
파일 끝의 일반적인 줄바꿈은 별도 항목을 추가하지 않습니다. 명시적인 빈 줄은 빈 항목으로 보존합니다.
<0>~<255>는 십진수 바이트 코드입니다. <0A> 같은 16진수 표기는 거부합니다.
<0> = 하위 문자열 구분/종료, <10> = 항목 내부 줄바꿈, <60> = '<', <62> = '>', <35> = '#'.
항목 끝에 <0>이 없으면 종료 바이트를 자동으로 추가합니다. 항목 내부 <0>과 기타 제어 코드는 보존합니다.
중간 항목 추가/삭제는 뒤 문자열 번호를 바꿉니다. 추가가 필요하면 마지막에 넣고 참조 데이터를 따로 설정하세요.
기본적인 1.16.1 호환 범위로 헤더 포함 파일 크기 65,535바이트 이하만 출력합니다.
출력은 문자열 개수(u16), 시작 오프셋 배열(u16), 문자열 바이트로 구성되며 저장 전 모든 항목을 재해독하여 비교합니다.

현재 TXT를 변환한 결과: output/stat_txt.tbl — 1564 항목, 41057바이트.
원본 TBL: 1547 항목, 40398바이트. TXT에 17개 항목이 더 있으므로 의도한 추가인지 확인하세요.
이 프로그램은 임의로 추가 항목/빈 줄을 지우거나 원래 인덱스로 복구하지 않습니다.

검증: CompilerTests.exe를 도구 폴더에서 실행합니다.
원본 TBL을 메모리에서 텍스트 코드로 변환 후 컴파일하여 바이트 단위로 원본과 일치하는 것을 확인했습니다.
output/original-roundtrip.tbl은 이 검증 결과이며 사용자 수정 TXT의 변환 결과와 구분하세요.
하위 문자열, 빈 항목, 공백 보존, 제어 코드, 잘못된 코드, 용량 초과, 인코딩 검사도 통과했습니다.
실제 StarCraft 1.16.1 게임 실행은 검증하지 않았습니다.

WinMPQ 내부 삽입 경로: rez\stat_txt.tbl
적용할 언어의 Locale로 넣고, 실제 게임에서 로드되는 모드 MPQ에 추가하세요.

명령줄:
TblCompiler.exe "input.txt" "output\stat_txt.tbl"
TblCompiler.exe "input.txt" "output\stat_txt.tbl" 949
